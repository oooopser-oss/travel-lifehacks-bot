# Travel & Lifehacks Autonomous Instagram Bot

Полностью автономный бот для блога о путешествиях и лайфхаках: публикует посты по расписанию без ручного участия после запуска.

## Формат контента

14 готовых постов на 2 недели, один в день, два типа чередуются:

- **Фото направлений** (`content_type: "photo"`) — реальные лицензированные фото Adobe Stock (пляж, горы, старый город, лес, водопад, пустыня, вид из самолёта), уже включены в `assets/stock_photos/`
- **Карточки-лайфхаки** (`content_type: "card"`) — генерируются автоматически: градиентный фон + текст совета (упаковка, бюджет, безопасность, лайфхаки)

Важно: в этом проекте **нет** автоматического текста-в-изображение — карточки это стилизованный текстовый дизайн, а не фотореалистичные картинки. Фотореалистичные кадры — только настоящие лицензированные стоковые фото.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

Заполни `.env`:
```
INSTAGRAM_USERNAME=твой_логин
INSTAGRAM_PASSWORD=твой_пароль
```

## Запуск

```bash
python3 main_publisher.py
```

При первом запуске потребуется войти в Instagram (возможен запрос кода подтверждения — instagrapi поддерживает 2FA). После успешного входа сессия сохраняется в `sessions/`.

Бот планирует все 14 постов по одному в день (начиная с завтра), время публикации чередуется между 09:00 / 14:00 / 19:00, и работает в фоне, пока процесс запущен.

## Добавление контента

Контент-план — список `POSTS_SCHEDULE` в `content_calendar.py`. Пост с фото направления:

```python
{
    "day": 15,
    "content_type": "photo",
    "photo_file": "assets/stock_photos/имя_файла.jpg",
    "caption": "...",
    "hashtags": "...",
}
```

Пост-карточка с лайфхаком:

```python
{
    "day": 16,
    "content_type": "card",
    "card_type": "lifehack",  # lifehack | packing | budget | safety
    "title": "...",
    "subtitle": "...",
    "caption": "...",
    "hashtags": "...",
}
```

Новые фото для направлений нужно подбирать и лицензировать вручную (например, через Adobe Stock) и класть в `assets/stock_photos/` — автоматической генерации фотореалистичных изображений в проекте нет.
